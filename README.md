# The Greek alphabet

A static reference page for all 24 Greek letters, with English names, uppercase
and lowercase glyphs, and their standard LaTeX expressions.

## Preview locally

Open `index.html` in a browser. There are no dependencies or build steps.

## Publish with GitHub Pages

1. Push the files to the repository's default branch.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the default branch and **`/ (root)`**, then save. GitHub will show the
   published URL on that page once deployment completes.
